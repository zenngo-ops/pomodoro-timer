# 🍅 ポモドーロ・タイマー

シンプルなポモドーロ・タイマーです。作業・短い休憩・長い休憩を切り替えながら時間を計測でき、その日のタスク管理もあわせて行えます。

## 機能

- 作業(25分) / 短い休憩(5分) / 長い休憩(15分)の3モード
- 円形のプログレスリングで残り時間を表示
- 完了したポモドーロ数をその日の分だけ記録(ブラウザのlocalStorageに保存)
- 4回の作業サイクルごとに自動で長い休憩へ切り替え
- タイマー終了時にアラーム音を再生
- 今日のタスクリスト(追加・完了チェック・削除・完了済みの一括消去)

## 使い方

### そのまま開く

`index.html` をブラウザで直接開くだけで動作します。

### ローカルサーバーで開く(Windows / PowerShell)

```powershell
./serve.ps1
```

起動後、ブラウザで `http://localhost:8934/` を開いてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面のマークアップ |
| `style.css` | スタイル(ライト/ダークモード対応) |
| `script.js` | タイマーとタスク管理のロジック |
| `serve.ps1` | ローカル確認用の簡易HTTPサーバー |

## 技術スタック

素のHTML / CSS / JavaScript(フレームワーク・ビルドツール不使用)
